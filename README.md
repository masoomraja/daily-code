## ▶️ How to Use

1. Install JDK 17 or later.
2. Clone the repository and open it in IntelliJ IDEA, Eclipse or VS Code.
3. Browse the monthly folders and read the problem statement at the top of each Java file.
4. Add test cases or a `main` method to run the standalone DSA solutions.
5. For Spring Boot snippets, create a Spring Boot project with the relevant starters and package structure.

```bash
git clone https://github.com/masoomraja/daily-code.git
cd daily-code
```

**Note:** Spring Boot files are focused learning snippets, not a complete runnable application by themselves. They require the matching Spring Boot dependencies and project configuration.
